# Week 1 reflection
1. What is the difference between building a UI imperatively (plain DOM code) and
declaratively (React)?
=Imperative tells the browser how to build the UI, while declarative (React) describes what the UI should look like.
2. Why must a component name start with a capital letter?
=To differ between React components and HTML elements 
3. What does a fragment <>...</> do, and why not just use a <div>?
=A fragment allows multiple elements to be grouped without adding an extra element to the HTML/DOM. A <div> would create an unnecessary container.
4. Name one benefit of splitting the UI into small components.
=To easier access and maintain.
